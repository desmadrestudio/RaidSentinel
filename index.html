Discord webhook

Where do I get the webhook URL?

A webhook is Discord's private posting link for one channel. Raid Sentinel uses it to send alerts to that channel.

  1. Open Discord and go to the channel that should receive raid alerts.
  2. Click the channel settings gear, then open Integrations.
  3. Open Webhooks, create a webhook, and name it Raid Sentinel.
  4. Click Copy Webhook URL.
  5. Paste that URL into Raid Sentinel and click Send Test Alert.

The webhook URL should start with https://discord.com/api/webhooks/. A Discord invite link will not work.

FAQ

Common questions before buying.

Do I get a license key?

Yes. Gumroad provides the license key after purchase. Paste it into Raid Sentinel to unlock monitoring.

Does it work if the game is minimized?

Screen reading works best with the selected game window open and readable. Server log mode is the better option when you can access server logs.

Can I cancel?

Subscription and billing are managed through Gumroad. If access is canceled, refunded, or disabled, the app can block monitoring after validation.

What do I need?

A Windows PC, the game/log source you want to monitor, and a Discord webhook URL for the channel that should receive alerts.

Why might Windows warn me?

Raid Sentinel is a new independent Windows app and is not code-signed yet. Only download it from your Gumroad purchase page or this official Raid Sentinel page.
